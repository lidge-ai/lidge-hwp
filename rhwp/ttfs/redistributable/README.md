# ttfs/redistributable — 공식 배포 원본 SFNT

권리자가 배포한 exact 원본 SFNT를 라이선스·출처와 함께 추적한다. 디렉터리 이름은 라이선스 분류가
아니다. 현재 Happiness Sans는 동봉된 공식 PDF에 따라 SIL OFL 1.1이다. 각 하위 디렉터리는 공식
source URL, archive/member hash, 동봉 라이선스를 기록한다. 원본 바이트를 유지하는 검증 정책과
라이선스가 허용하는 수정·재배포 범위는 구분한다.

이 경로의 폰트는 fixture·exact-source 검증 입력이다. 별도 제품 결정 없이 WASM이나 배포 bundle에 자동
포함하지 않는다.
